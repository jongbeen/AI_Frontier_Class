## §1. 생물학적 뉴런과 인공 신경망 `P.3~P.5`

### 1-1. 생물학적 비유 `P.3`
- 뇌는 **서로 연결된 뉴런의 덩어리**이고, 뉴런들은 서로 신호를 주고받아.
- **뉴런**이란: 뇌에서 정보 처리를 하는 세포이자, 신경계 조직의 **기본 기능 단위**.
- 신호를 전달할지 말지는 **all-or-nothing(전부 아니면 전무)** 사건이야.
  - 뉴런 세포 안의 **전기 전위가 임계값(threshold)**을 넘는지로 결정돼.
  - 신호를 보낼지는 두 뉴런 사이의 **연결 강도(시냅스)**에 달려 있어.

> 💡 이 두 아이디어가 그대로 인공 뉴런이 돼. **시냅스 강도 → 가중치(w)**, **임계값을 넘으면 발화 → 활성화 함수**.

### 1-2. 뇌와 컴퓨터 비교 `P.4`
- 뉴런은 **느리다**: 게이트보다 약 **백만 배** 느려.
- 대신 **병렬성과 연결성**이 압도적이야: 뇌는 한 스텝에 모든 뉴런을 발화시킬 수 있고, 약 **10¹⁵개의 시냅스**로 연결돼 있어.

| 항목 | 인간(뇌) | 컴퓨터 |
|---|---|---|
| 처리 요소 | 1,000억 개 뉴런 | 1,000만 개 게이트 |
| 연결(Interconnects) | 뉴런당 1,000개 | 몇 개 |
| 초당 사이클 | 1,000 | 5억 |
| 대역폭 | 10조 bits/sec | 10억 bits/sec |
| 2배 향상에 걸리는 시간 | 20만 년 | 2년 |

- 정리하면 컴퓨터는 **개별 소자가 훨씬 빠르고**, 뇌는 **병렬 연결과 대역폭**에서 압도해. 신경망은 후자의 방식을 흉내 낸 거야.

### 1-3. 인공 신경망이란 `P.5`
- **ANN(Artificial Neural Network)** 또는 **MLP(Multi-Layer Perceptron)**라고 불러.
- 정의: **병렬로 동작하는 많은 단순 처리 요소**로 이루어진 시스템으로, **경험적 지식을 획득·저장·활용**할 수 있어.
- 중요한 주의: **생물학적 뉴런은 인공 뉴런과 같지 않아.**
  - 실제 뉴런은 **복잡한 비선형 계산**을 하고,
  - **복잡한 비선형 동역학계**라서 **타이밍이 중요**해.

## §2. 인공 뉴런(유닛)의 계산 `P.6~P.7`

### 2-1. 뉴런 vs 유닛 `P.6`
- ANN의 각 요소는 **유닛(unit)**이라는 노드야.
- 유닛들은 **링크(link)**로 연결되고, 각 링크에는 **수치 가중치**가 있어.
- 실제 뉴런은 이 단순화된 모델과 **많이 달라.**
- 그림 대응 관계:

| 생물학적 뉴런 | 유닛 |
|---|---|
| 수상돌기(dendrite)로 신호를 받음 | 입력 `xᵢ`에 가중치 `wᵢ`를 곱함 (`wᵢxᵢ`) |
| 시냅스 | 가중치 `wᵢ` |
| 세포체(cell body)에서 신호 합산 | `Σ wᵢxᵢ + b` |
| 임계값을 넘으면 발화 | 활성화 함수 `f` |
| 축삭(axon)으로 출력 | 출력 `f(Σ wᵢxᵢ + b)` |

### 2-2. 유닛 안의 계산 `P.7`
유닛은 두 단계로 계산해.

**① 선형 입력 함수**: 입력의 **가중합**을 계산

```
h = Σᵢ wᵢ xᵢ + b
```
- `wᵢ`: 가중치(weights), `b`: 편향(bias)

**② 비선형 활성화 함수**: 합을 **활성화 수준(단일 출력)**으로 변환

```
f(h) = f( Σᵢ wᵢ xᵢ + b )
```

- 슬라이드 예시(입력 3개): 입력 `x₁, x₂, x₃`, **입력마다 가중치 하나** `w₁, w₂, w₃`, **유닛마다 편향 하나** `b`

```
f(h) = f( w₁x₁ + w₂x₂ + w₃x₃ + b )
```

> 💡 **편향 `b`의 역할 (보충)**: 입력이 전부 0이어도 유닛이 내보낼 수 있는 기본값을 조절해. 활성화 함수가 켜지는 문턱을 옮겨주는 "기준점 조절 손잡이"라고 보면 돼.

**(보충) 숫자 예시**: `x = (1, 2, 3)`, `w = (0.5, −1, 0.2)`, `b = 0.1`이면
`h = 0.5 − 2 + 0.6 + 0.1 = −0.8`

| 활성화 함수 | 출력 |
|---|---|
| ReLU | 0 |
| Sigmoid | 약 0.31 |
| Tanh | 약 −0.66 |

같은 `h`라도 어떤 함수를 쓰느냐에 따라 출력이 달라지는 걸 볼 수 있어.

## §3. 활성화 함수 `P.8~P.11`

활성화 함수의 비선형성이 없으면 층을 아무리 쌓아도 하나의 선형 함수와 같아져. 그래서 비선형 `f`가 꼭 필요해. (딥러닝 입문 노트의 "여러 층의 **비선형** 처리 단위" 이야기와 같은 이유야.)

### 3-1. Sigmoid `P.8`

```
σ(x) = 1 / (1 + e^(−x))
```
- 출력을 **[0, 1]**로 눌러 담아(squash).
- 역사적으로 인기가 많았던 이유: **생물학적 뉴런의 포화되는 발화율(saturating firing rate)**로 해석하기 좋아서.
- 도함수: `f′(x) = f(x)(1 − f(x))` (그래프에서 파란 곡선, 최댓값 0.25)

**두 가지 큰 문제**

| 문제 | 설명 |
|---|---|
| ① **포화된 뉴런이 기울기를 죽임** (saturated neurons kill the gradient) | 입력이 매우 크거나 작으면 곡선이 평평해져(그래프의 빨간 화살표 구간) 도함수가 거의 **0**. 그러면 학습 신호(기울기)가 사라져서 가중치가 거의 갱신되지 않아. |
| ② **출력이 zero-centered가 아님** (항상 양수) | 다음 층 유닛의 입력이 전부 양수면 그 가중치 `w`의 기울기가 **전부 같은 부호(모두 양수 또는 모두 음수)**가 돼서, 갱신이 **지그재그**로 비효율적으로 진행돼. |

> 💡 **②의 이유 (보충)**: 가중치 `wᵢ`의 기울기는 (뒤에서 오는 신호) × `xᵢ` 꼴이야. `xᵢ`가 전부 양수면 모든 `wᵢ`의 기울기는 뒤에서 오는 신호와 같은 부호를 가져. 그래서 가중치들이 "다 같이 올라가거나 다 같이 내려가기"만 할 수 있어서 원하는 방향으로 곧장 가지 못하고 지그재그로 가.

### 3-2. Tanh `P.9`

```
tanh(x) = (eˣ − e^(−x)) / (eˣ + e^(−x))
```
- 출력 범위 **[−1, 1]**.
- **zero-centered** → Sigmoid의 문제 ②는 해결.
- 도함수: `f′(x) = 1 − f(x)²`
- 하지만 **문제 ①(포화되면 기울기 소실)은 여전히 남아 있어.** (그래프의 양 끝이 평평)

### 3-3. ReLU `P.10`

```
f(x) = max(0, x)
```
- **포화하지 않고** 계산이 매우 효율적이야 (비교 한 번).
- 실제로 sigmoid/tanh보다 **훨씬 빠르게 수렴**해.
- 문제: **어떤 유닛은 영영 활성화되지 않을 수 있어.** `x < 0`이면 **기울기가 0**이라서, 한 번 그 구간에 빠지면 갱신이 안 돼 (이를 흔히 "dead unit"이라고 불러).

### 3-4. Parametric ReLU (PReLU) `P.10`

```
f(x) = 1(x<0)·a·x + 1(x≥0)·x      (a는 작은 값)
```
- `x ≥ 0`이면 그대로 `x`, `x < 0`이면 작은 기울기 `a`를 곱해서 음수 영역에서도 **기울기가 0이 아니게** 해.
- `a = 0`이면 **ReLU**가 돼: `f(x) = max(0, x)`.
- 도함수: `x < 0`에서 `a`, `x ≥ 0`에서 `1`.

### 3-5. 실전 조언 (CNN 기준) `P.11`

| 권고 | 내용 |
|---|---|
| **ReLU를 써라!** | 대부분의 문제에서 좋은 **기본 선택**. 단, **학습률**에 주의하고 네트워크의 **죽은 유닛 비율을 모니터링**할 것 |
| 대안 시도 | **Leaky ReLU**나 **tanh**를 시도해볼 수 있음 |
| **Sigmoid는 더 이상 쓰지 마라** | (은닉층 활성화 기준) |
| 단, 이 주장들은 바뀔 수 있다 | "Stay tuned! The above arguments can be nullified!" |
| 최근 인기 함수 | **ELU**(Exponential Linear Unit), **GELU**(Gaussian Error Linear Unit), **Swish** 등 |

- 참고 논문(슬라이드): Kunc & Kléma, *Three Decades of Activations: A Comprehensive Survey of 400 Activation Functions for Neural Networks*, arXiv 2024 — 활성화 함수만 400개를 정리한 서베이야.

> 💡 **(보충) Leaky ReLU와 PReLU**: 둘 다 음수 영역에 작은 기울기를 둬. 보통 Leaky ReLU는 `a`를 고정된 작은 값으로 두고, PReLU는 `a`를 학습하는 파라미터로 취급해.

**활성화 함수 비교표**

| 함수 | 수식 | 출력 범위 | zero-centered | 기울기 소실 | 비고 |
|---|---|---|---|---|---|
| Sigmoid | `1/(1+e⁻ˣ)` | [0, 1] | ❌ | 있음 (포화) | 지금은 비권장 |
| Tanh | `(eˣ−e⁻ˣ)/(eˣ+e⁻ˣ)` | [−1, 1] | ✅ | 있음 (포화) | sigmoid보다 낫지만 문제 ① 잔존 |
| ReLU | `max(0, x)` | [0, ∞) | ❌ | 양수 영역은 없음 | 기본 선택, 죽은 유닛 주의 |
| PReLU | `x<0`이면 `ax`, 아니면 `x` | (−∞, ∞) | — | 음수 영역도 기울기 `a` | `a=0`이면 ReLU |

> ReLU의 zero-centered 항목은 슬라이드가 직접 다루지 않은 부분이라, 출력이 0 이상이라는 사실만 ❌로 표시했어 **(보충)**.

## §4. 순전파 신경망(Feedforward NN) `P.12~P.14`

### 4-1. 구조의 특징 `P.13`
- **유연한 구조**: 층을 **몇 개든** 쌓을 수 있고, 입출력 유닛도 **몇 개든** 가질 수 있어.
- 각 유닛은 **오직 다음 층의 유닛과만** 연결돼.
- 연결되지 **않는** 경우: 같은 층 안의 유닛끼리, 이전 층으로 되돌아가는 연결, 층을 건너뛰는 연결.
- 그림의 예시: 입력 `x₁, x₂, x₃` → 은닉층 → 출력 하나.

> 💡 정보가 입력에서 출력 방향으로 **한 방향으로만 흐르기** 때문에 "feedforward(순방향)"라고 불러.

### 4-2. 표기법 `P.14`

| 기호 | 뜻 |
|---|---|
| `W_ij^(l)` | **층 `l`의 유닛 `j`에서 층 `l+1`의 유닛 `i`로 가는 가중치** |
| `a_i^(l)` | 층 `l`의 유닛 `i`의 **활성화(출력값)** |
| `a_i^(1) = x_i` | 입력층의 활성화는 **`i`번째 입력** 자체 |
| `L` | 층의 개수 |
| `b_i^(l)` | 층 `l+1`의 유닛 `i`에 더해지는 편향 |
| `h(x)` | 네트워크의 최종 출력 (= `a^(L)`) |

- **파라미터 수 = #W + #b**
  - `#W` = **엣지(연결선) 수**
  - `#b` = **노드 수** (슬라이드 표기)

> 💡 **(보충) 예시로 세어보기**: 슬라이드 그림처럼 입력 3개 → 은닉 3개 → 출력 1개이면
> - 가중치: 입력→은닉 `3×3 = 9`개 + 은닉→출력 `3×1 = 3`개 = **12개**
> - 편향: 은닉 3개 + 출력 1개 = **4개** (편향은 은닉·출력 유닛에만 붙으므로 **입력 노드는 제외**하고 세는 게 정확해. 슬라이드의 "노드 수"는 이런 의미로 읽으면 돼)
> - 총 **16개** 파라미터

- 그림의 `W_ij` 위첨자는 **어느 층 → 어느 층** 연결인지를 나타내. 첫 번째 가중치 묶음 `W^(1)`은 입력→은닉, 두 번째 `W^(2)`는 은닉→출력이야.

## §5. 순전파(Forward Propagation) `P.15~P.16`

순전파 = 입력을 넣어서 **앞에서 뒤로 차례차례 계산해 출력을 얻는 과정**이야.

### 5-1. 유닛별로 풀어쓴 계산 `P.15`
먼저 새 기호: **`z_i^(l)`** = 층 `l`의 유닛 `i`로 들어오는 **입력의 총 가중합** (활성화 함수를 거치기 전 값).

**은닉층 (층 2)** — 각 유닛마다:
```
a₁^(2) = f( W₁₁^(1)x₁ + W₁₂^(1)x₂ + W₁₃^(1)x₃ + b₁^(1) ) = f( z₁^(2) )
a₂^(2) = f( W₂₁^(1)x₁ + W₂₂^(1)x₂ + W₂₃^(1)x₃ + b₂^(1) ) = f( z₂^(2) )
a₃^(2) = f( W₃₁^(1)x₁ + W₃₂^(1)x₂ + W₃₃^(1)x₃ + b₃^(1) ) = f( z₃^(2) )
```

**출력층 (층 3)**:
```
h(x) = a₁^(3) = f( W₁₁^(2)a₁^(2) + W₁₂^(2)a₂^(2) + W₁₃^(2)a₃^(2) + b₁^(2) ) = f( z₁^(3) )
```

- 일반식: 예를 들어 `z_i^(2) = Σ_{j=1}^{3} W_ij^(1) x_j + b_i^(1)`

→ 즉 **각 층의 출력이 다음 층의 입력**이 돼.

### 5-2. 행렬 형태 `P.16`
유닛마다 식을 쓰는 대신 **벡터와 행렬**로 묶으면 층 전체를 한 줄로 계산해.

```
z^(2) = W^(1) x + b^(1)
a^(2) = f( z^(2) )
z^(3) = W^(2) a^(2) + b^(2)
h(x) = a^(3) = f( z^(3) )
```

- `f`를 벡터에 적용하면 **원소별(element-wise)**로 적용돼.
- 이걸 **재귀적으로** 계산하는 일반식:

```
a^(1) = x
z^(l+1) = W^(l) a^(l) + b^(l)
a^(l+1) = f( z^(l+1) )
```

> 💡 **(보충) 왜 행렬로 쓸까?** 딥러닝 입문 노트에서 본 "균일한 병렬 연산이 GPU에 잘 맞는다"는 이야기와 직접 연결돼. 층 하나가 "행렬곱 + 원소별 함수"라서 GPU가 한 번에 처리하기 좋아.

**차원 감 잡기 (보충)**: 층 `l`에 유닛이 `n_l`개이면
- `W^(l)`의 크기 = `n_{l+1} × n_l`
- `b^(l)`의 크기 = `n_{l+1}`
- 예시 네트워크(3-3-1): `W^(1)`은 `3×3`, `W^(2)`는 `1×3`

## 한눈에 보는 핵심 정리표

**생물학적 뉴런 → 인공 뉴런 대응**

| 생물학 | 인공 신경망 |
|---|---|
| 시냅스 강도 | 가중치 `w` |
| 신호 합산 | 가중합 `Σ wᵢxᵢ + b` |
| 임계값을 넘으면 발화 | 활성화 함수 `f` |
| 뉴런들의 연결망 | 층으로 쌓은 유닛들 |

**순전파 핵심 공식**

| 구분 | 수식 |
|---|---|
| 단일 유닛 | `a = f(Σ wᵢxᵢ + b)` |
| 한 층 (행렬) | `z^(l+1) = W^(l)a^(l) + b^(l)`, `a^(l+1) = f(z^(l+1))` |
| 파라미터 수 | `#W`(엣지 수) + `#b`(은닉·출력 노드 수) |
