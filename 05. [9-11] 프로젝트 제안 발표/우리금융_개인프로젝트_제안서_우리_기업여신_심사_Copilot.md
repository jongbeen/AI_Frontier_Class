# [개인 프로젝트 제안서] Generative AI 기반 기업 여신 심사 자동화 및 실시간 리스크 센싱 시스템 (Woori Corporate Credit Copilot)

본 제안서는 **2026년 하반기 서울대 AI 프론티어 마스터 과정** 개인 프로젝트 제안 발표용으로 기획되었습니다. 우리금융그룹의 핵심 금융 비즈니스인 '기업 여신(대출) 심사' 업무의 페인 포인트(Pain Point)를 해결하고, 최신 Multi-Agent 및 RAG 기술을 결합하여 실무 적용성과 기술적 타당성을 모두 극대화한 프로젝트 기획안입니다.

## [Slide 1] 프로젝트 주제 및 문제 정의 (Title & Problem Definition)

### 1. 과제명
**Generative AI 기반 기업 여신 심사 자동화 및 실시간 리스크 센싱 시스템 (Woori Corporate Credit Copilot)**

### 2. 제안 배경 (Pain Point)
* **심사역의 과도한 업무 로드**: 기업 여신 심사 시, 심사역은 수십 장에 달하는 기업분석 보고서, 재무제표, 산업 동향, 뉴스 등을 수작업으로 수집하고 분석해야 함. 보고서 초안 작성에만 기업당 평균 **2~3일**이 소요되어 적시 지원에 한계가 있음.
* **비정형 리스크 센싱 지연**: 기업의 돌발 리스크(경영진 횡령/배임, 중대 재해 소송, 특허 분쟁 등)는 정형 재무제표에 뒤늦게 반영됨. 실시간 리스크 감지가 지연될 경우 거액의 여신 부실화 위험에 직면함.
* **블랙박스형 AI 도입의 한계**: 여신 심사는 거절 사유에 대한 설명 의무(Explainability)가 법적으로 따르는 영역임. 일반적인 엔터프라이즈 LLM의 단독 판단은 환각(Hallucination) 우려 및 불투명성으로 인해 실제 현업 도입이 불가함.

### 3. 해결 방안 (Solution)
* 정형 데이터(재무지표)는 **DART API**를 활용한 규칙 기반 수집으로 정확도를 100% 확보하고, 비정형 데이터(뉴스, 리서치)는 **Multi-Agent 기반 RAG(Retrieval-Augmented Generation)**로 수집/가공함.
* 실시간 리스크를 정밀 센싱하여 대시보드에 시각화하고, 규격화된 **여신심사보고서(Credit Memo) 초안**을 자동 생성하여 심사역이 '최종 의사결정'에만 집중할 수 있도록 돕는 **심사 Copilot**을 구축함.

## [Slide 2] 현업 과제 해결 및 기대 효과 (Business Value & Expected Benefits)

```
[ 기존 여신 심사 프로세스 ]
자료 수집 (DART, 뉴스) ──> 지표 분석 및 리스크 진단 ──> 심사보고서 작성 ──> 최종 심사 의사결정 (2~3일 소요)
                                 ▼
[ Woori Corporate Credit Copilot 적용 후 ]
심사역 기업명 입력 ──> Multi-Agent 자동 수집 및 실시간 리스크 센싱 ──> 초안 자동 도출 ──> 심사역 판단 및 최종 승인 (10분 내 완료)
```

### 1. 해결하고자 하는 현업/업무 과제
* **데이터 수집 및 정형 양식 작성 자동화**: 심사 프로세스 중 가장 많은 시간이 소요되는 기본 정보 취합 및 재무분석 작성 단계를 자동화함.
* **정성적 리스크의 정량화 및 센싱**: 복잡하게 흩어진 뉴스 및 공시 정보에서 부정적 이슈를 조기 탐지하고 리스크 심각도를 자동으로 지표화함.

### 2. 비즈니스 기대 효과
* **업무 효율성 극대화**: 심사 보고서 작성에 소요되는 시간을 **2~3일에서 10분 내외로 단축**하여 신속한 여신 승인 프로세스 구현 (고객 만족도 제고).
* **부실 여신 선제적 방어 (NPL 감소)**: 정형 데이터에 잡히지 않는 비정형 부정 신호를 조기 탐지하여 여신 부실화로 인한 손실 예방.
* **심사 보고서의 정합성 및 일관성 제고**: 표준 템플릿과 정교화된 RAG를 기반으로 보고서를 생성함으로써, 담당 심사역의 주관에 따른 편향을 배제하고 표준화된 수준의 심사 품질을 상시 유지.

## [Slide 3] 사용 예정 데이터 및 활용 방안 (Data Acquisition & Utilization)

현업의 망분리 규제 및 보안 정책을 완벽히 준수하기 위해, 실제 내부망 데이터 유출 없이 프로토타입을 완성할 수 있도록 **가명/가상 정보 및 공공/외부 API**를 중심으로 파이프라인을 설계합니다.

### 1. 정형 데이터 (Hard Data)
* **금융감독원 전자공시시스템(DART) API**: 대상 기업의 최근 3개년 재무제표(손익계산서, 재무상태표, 현금흐름표) 수집 및 핵심 재무 비율(부채비율, 유동비율, 영업이익률 등) 추출.
* **한국거래소(KRX) 및 공공데이터포털 기업 기본 정보**: 기업 개요, 소속 산업군, 지배구조(대주주 지분 현황) 등 수집.
* **활용 방안**: LLM을 배제하고 **API 파싱 및 코딩 기반(Python/Pandas)**으로 추출하여, 핵심 재무 정보의 **환각 가능성을 0%로 통제**.

### 2. 비정형 데이터 (Soft Data)
* **포털 뉴스 API (네이버/다음)**: 기업명 및 리스크 키워드(예: '피소', '횡령', '부도', '규제', '워크아웃' 등) 조합을 통한 최근 1년 치 부정 뉴스 수집.
* **우리금융경영연구소 및 금융사 리서치 보고서**: 대상 기업이 속한 산업의 시장 동향, 위협 요인(SWOT), 거시경제적 영향 수집.
* **활용 방안**: 수집된 텍스트 데이터를 정제 후 **Chroma DB(Vector DB)**에 임베딩하고 적재하여, RAG 기반의 기업 정성 리스크 평가 및 보고서 본문 작성을 위한 근거 데이터셋으로 사용.

## [Slide 4] 적용 예정 기술 및 모델 아키텍처 (Applied Technology & Architecture)

설명 가능성과 보안성을 동시에 확보하기 위해 **Multi-Agent 시스템(LangGraph)**과 **Hybrid RAG** 방식을 설계합니다.

```
                  ┌────────────────────────────────────────────────────────┐
                  │                      [ 사용자 UI ]                     │
                  │             Streamlit 기반 심사역 대시보드              │
                  └──────────────────────────┬─────────────────────────────┘
                                             │ 기업명 입력 / 심사 요청
                                             ▼
                  ┌────────────────────────────────────────────────────────┐
                  │            [ LangGraph Multi-Agent Control ]           │
                  │             단계별 분기 흐름 및 상태 관리               │
                  └───────┬──────────────────┬───────────────────┬─────────┘
                          │                  │                   │
                          ▼                  ▼                   ▼
┌───────────────────────────┐ ┌───────────────────────────┐ ┌───────────────────────────┐
│       [ Data Agent ]      │ │      [ Risk Agent ]       │ │     [ Drafting Agent ]    │
│  - DART/KRX API 정형 분석 │ │  - 뉴스/리서치 RAG 탐색   │ │  - 보고서 포맷 조립       │
│  - 재무 지표 자동 산출    │ │  - 부정 감성/키워드 스코어│ │  - On-Premise LLM 양식화  │
└───────────────────────────┘ └───────────────────────────┘ └───────────────────────────┘
```

### 1. 주요 적용 기술 및 오픈소스 라이브러리
* **Multi-Agent Orchestration (LangGraph)**: 업무 프로세스가 정교하게 정의되어야 하는 심사 특성에 맞춰, 에이전트 간의 역할 분담 및 피드백 루프(Flow Control)를 제어하여 복잡한 심사 단계를 체계적으로 통제.
* **RAG & Vector DB (ChromaDB / LangChain)**: 수집된 비정형 보고서와 뉴스를 청킹(Chunking) 및 벡터화하여, LLM이 문서를 작성할 때 정확한 원문 출처(Citation)와 근거 요약을 제공하도록 구축.
* **LLM (GPT-4o & On-Premise SLM Hybrid)**:
  * **외부망 GPT-4o**: 정성적 리서치 분석, 뉴스 키워드 감성 분석 등 높은 고도의 추론 성능이 필요한 비정형 데이터 정제에 활용.
  * **내부망 On-Premise SLM (Llama-3-Ko 등)**: 수집 및 정제된 결과값들을 최종 보고서 서식(Credit Memo 템플릿)에 맞춰 조합하고 최종 초안을 도출하는 내부 문서 작성을 담당하여 데이터 외부 유출 원천 차단.
* **시연용 UI (Streamlit)**: 심사역이 대상 기업명을 입력하면 **[정형 재무 상태 요약 + 실시간 부정 뉴스 센싱 점수(Risk Gauge) + 생성된 여신심사보고서 PDF/MD 초안 미리보기 및 다운로드]**를 원스톱으로 지원하는 인터페이스 구현.

## [Slide 5] 개발 계획 및 평가지표 (Execution Roadmap & Evaluation Metrics)

### 1. 현실화 가능한 개발 로드맵 (6 ~ 18주차, 총 12주)
* **6 ~ 8주차 (3주) [데이터 파이프라인 개발 및 데이터 가상화]**
  * DART API 및 KRX Open API 연동 모듈 개발.
  * 네이버 뉴스 및 주요 리서치 보고서 크롤링 엔진 설계.
  * 가상 테스트 기업 10개사에 대한 가명 데이터셋 구축 및 Chroma Vector DB 임베딩.
* **9 ~ 11주차 (3주) [Multi-Agent 아키텍처 및 RAG 구축]**
  * LangGraph 기반의 Workflow 흐름도 설계 (Data Agent -> Risk Agent -> Drafting Agent).
  * 리스크 키워드 분석 및 뉴스 감성 분석 감지 로직 구체화.
  * 각 에이전트 단계별 RAG 시스템 연동 및 프롬프트 엔지니어링 최적화.
* **12 ~ 14주차 (3주) [보고서 자동화 모듈 및 Streamlit UI 개발]**
  * 생성된 정량/정성 데이터를 기반으로 표준 여신심사보고서 포맷(PDF/Markdown)으로 파일화하는 엔진 구축.
  * Streamlit을 활용한 직관적인 웹 대시보드(실시간 위험 등급 히트맵 및 보고서 생성기) 개발.
* **15 ~ 17주차 (3주) [시스템 통합 테스트, 평가 및 고도화]**
  * 전체 프로세스 종단 간(End-to-End) 연동 및 오작동 검증.
  * 최종 평가지표 측정을 통한 프롬프트 튜닝 및 환각 제거 작업.
* **18주차 (1주) [최종 발표 준비 및 데모 영상 제작]**
  * 실제 구동 영상을 포함한 우수 프로젝트 최종 발표 자료 작성.

### 2. 평가 지표 및 검증 타당성 (KPI)
* **정량적 평가 지표 (Technical Performance)**:
  1. **재무 정보 정합성 (Hard Data Accuracy)**: AI가 자동 수집하여 보고서에 채워 넣은 재무 수치와 DART 원본 공시자료의 수치를 크로스체킹하여 **일치율 100% 확보** (규칙 기반 추출 검증).
  2. **보고서 생성 성공률 (Generation Rate)**: 10개 가상 기업에 대해 프로세스가 중단되거나 API 에러 없이 최종 보고서 다운로드까지 도달하는 비율 **95% 이상**.
* **정성적 평가 지표 (Expert Evaluation)**:
  1. **원문 근거성 (ROUGE / BERTScore)**: 생성된 리스크 심사평가 문장들과 Vector DB 상의 원문 데이터(뉴스, 공시) 간의 문맥적 유사도를 검증하여 **BERTScore 0.82 이상** 달성 (출처 검증).
  2. **현업 유용성 평가 (Fidelity Blind Test)**: 실제 우리은행/우리금융지주 여신 담당자 3인에게 AI가 생성한 보고서와 사람이 작성한 보고서를 블라인드로 비교 평가하게 하여 **실무 적용 가능성 점수 5점 만점에 4점 이상** 획득 목표.
