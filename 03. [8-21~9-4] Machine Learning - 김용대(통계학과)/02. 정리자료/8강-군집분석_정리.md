## §1. 군집분석 입문 `P.2~P.11`

### 1-1. 군집분석의 정의 `P.3`
군집분석은 **모집단이나 범주에 대한 사전 정보가 없는 상태**에서, 관측값들 사이의 거리(또는 유사성)만 가지고 전체를 몇 개의 집단으로 묶어내는 분석법이야. 그렇게 나눈 뒤 각 집단의 성격을 들여다보면서 데이터 전체 구조를 이해하는 게 목적이지.

> 💡 지도학습(회귀, 분류)은 "정답(y)"이 있어서 그걸 맞추는 훈련을 하지만, 군집분석은 애초에 정답이 없는 **비지도학습**이야. "이 데이터가 몇 개의 그룹으로 나뉠 것 같다"는 걸 순전히 거리 정보만으로 알아내는 거지.

### 1-2. 군집분석의 응용 `P.4`
- **고객 세그멘테이션**: 고객을 몇 개 그룹으로 나눠서 세그먼트별로 다른 마케팅을 하는 것
- **군집별 예측모형**: 하나의 모형 대신 군집(예: 남녀별, 소득별)마다 따로 예측모형을 만들면 더 잘 맞을 수 있음
- **데이터 압축**: 비슷한 데이터를 하나로 묶어 검색 등에 활용

### 1-3. 비유사성의 척도: 거리 `P.5`
군집분석의 핵심 재료는 "이 두 관측값이 얼마나 다른가"를 재는 척도야. 보통은 유사성(similarity)보다 **비유사성(dissimilarity)**, 즉 거리(distance)를 쓴다.

거리 `d(x,y)`가 진짜 "거리"이려면 다음 네 조건을 만족해야 해:
```
d(x,y) = 0  ⟺  x = y      (같으면 거리 0, 거리 0이면 같은 점)
d(x,y) >= 0               (거리는 항상 0 이상)
d(x,y) = d(y,x)            (대칭성: 어느 방향에서 재도 같음)
d(x,y) <= d(x,z) + d(z,y)  (삼각부등식: 우회하면 더 멀거나 같음)
```

> 💡 우리가 직관적으로 아는 "거리"의 성질을 수학적으로 정의한 거야. 특히 삼각부등식은 "지름길이 항상 최단거리다"라는 상식을 수식으로 표현한 것.

### 1-4. 거리 측도의 종류들 `P.6~P.7`

**유클리드 거리** (`P.6`) — 가장 흔히 쓰는 "직선거리"
```
d(x,y) = (Σ (x_i - y_i)²)^(1/2)
```
p=2차원이면 우리가 아는 피타고라스 공식 `d(x,y) = √((x1-y1)² + (x2-y2)²)` 그대로야.

**그 외 거리들** (`P.7`):
- **Minkowski 거리**: `d(x,y) = (Σ (x_i - y_i)^m)^(1/m)` — 유클리드 거리의 일반화 버전. m=2면 유클리드 거리가 되고, m을 바꾸면 다른 성질의 거리가 됨
- **표준화 거리**: `d(x,y) = (Σ ((x_i-y_i)/s_i)²)^(1/2)` — 각 변수를 그 변수의 표준편차 `s_i`로 나눠서 "단위 차이"를 보정한 거리
- **Mahalanobis 거리**: `d(x,y) = x' Σ⁻¹ y` — 변수들 간의 상관관계(공분산 Σ)까지 고려한 거리

> 💡 표준화 거리와 Mahalanobis 거리는 나중에 §3-6 "단위 변환" 문제와 바로 연결돼. 변수마다 단위(원, cm, 개수 등)가 다르면 그냥 유클리드 거리를 쓰는 게 위험하기 때문에 나온 방법들이야.

### 1-5. 범주형 자료의 거리 `P.8`
변수가 숫자가 아니라 성별·학력처럼 범주형이면, "불일치 항목수"를 거리로 쓸 수 있어. 예를 들어 아래 표에서:

| 개체 | 성별 | 학력 | 출신지역 |
|---|---|---|---|
| A | 남자 | 고졸 | 경기 |
| B | 여자 | 고졸 | 전남 |
| C | 남자 | 대졸 | 경기 |

`d(A,B)=2` (성별·출신지역 2개 항목이 다름), `d(A,C)=1` (학력 1개만 다름), `d(B,C)=3` (전부 다름). 즉 몇 개의 항목이 서로 다른가를 그대로 거리로 쓰는 방식이야.

### 1-6. 군집분석의 유형 `P.9~P.10`
- **상호배반적(disjoint) 군집**: 각 관측치가 여러 군집 중 **딱 하나에만** 속함 (예: 한국인/중국인/일본인)
- **계보적(hierarchical) 군집**: 한 군집이 다른 군집 안에 포함되는 나무(트리) 구조 (예: 전자제품 → 주방용 → 냉장고). 군집 간 중복 없이 계층을 이룸
- **확률 군집**: 어느 한 군집에 완전히 속한다고 딱 잘라 말하지 않고, "각 군집에 속할 확률"로 표현 (예: 군집 A에 속할 확률 0.7, 군집 B에 속할 확률 0.3)

### 1-7. 군집분석의 특징 `P.11`
- 유사성/비유사성을 어떻게 정의하느냐, 군집 형태를 어떻게 잡느냐에 따라 매우 다양한 방법이 존재
- 사전 정보 없이 분석하는 방법이라 **분석자의 주관**에 따라 결과가 달라질 수 있음
- 그래서 한 번에 끝내지 않고 여러 번 결과를 관찰하며 의미 있는 정보를 뽑아내야 함
- 특이값(이상치) 발견이나 결측값 보정에도 활용 가능
- **어떤 변수를 쓸지(변수 선택)**가 결과에 큰 영향을 미침

## §2. 계층적 군집분석 `P.12~P.23`

### 2-1. 계층적 군집분석의 개요 `P.13`
계층적 군집분석은 크게 두 방향이 있어:
- **병합(agglomeration)**: 가까운 관측값들끼리 하나씩 묶어 나가는 방법 (아래에서 위로)
- **분할(division)**: 먼 관측값들을 나누어가는 방법 (위에서 아래로)

실제로는 **병합 방법이 주로 사용**돼. 결과는 나무구조인 **덴드로그램(dendrogram)**으로 표현하는데, 이걸 보면 전체 군집들 간의 구조적 관계를 한눈에 파악할 수 있어.

### 2-2. 병합방법의 절차 `P.14~P.15`
1. 처음엔 n개의 자료를 각각 하나의 군집으로 본다 (군집 수 = n)
2. 그중 **가장 가까운 두 군집**을 병합 → 군집 수 n-1개
3. 다시 그중 가장 가까운 두 군집을 병합 → 군집 수 n-2개
4. 이를 반복하며 군집 수를 계속 줄여감
5. 시작 부분엔 군집 크기가 작고 동질적, 끝으로 갈수록 군집 크기가 커지고 이질적이 됨

이때 "군집들 간의 거리"를 어떻게 재느냐에 따라 최단거리, 최장거리, 평균거리 등 여러 방법이 갈려.

> 💡 개별 관측값 간 거리는 명확한데, "군집(여러 점의 묶음)" 간 거리는 정의하기 나름이야. 이걸 정하는 기준이 바로 아래 최장연결법 같은 것들이지.

### 2-3. 최장(완전)연결법 (Complete Linkage Method) `P.16`
**정의**: 두 군집 사이의 거리를, 각 군집에서 관측값을 하나씩 뽑았을 때 나올 수 있는 거리 중 **최댓값**으로 잡는다.
- 즉, 같은 군집에 속한 관측치들은 알려진 "최대 거리"보다 항상 가깝다는 게 보장됨
- **군집 내부의 응집성**(다들 서로 너무 멀지 않아야 함)에 중점을 두는 방식

### 2-4. 최장연결법 예제 — 손으로 풀어보는 병합 과정 `P.17~P.23`

**초기 거리행렬** (`P.17`) — 5개 관측값(1~5) 사이의 거리:

| | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | 0 | | | | |
| 2 | 7 | 0 | | | |
| 3 | 1 | 6 | 0 | | |
| 4 | 9 | 3 | 8 | 0 | |
| 5 | 8 | 5 | 7 | 4 | 0 |

**1단계** (`P.18`): 가장 가까운 쌍은 `d(1,3)=1`. → 군집 (1,3) 생성. 남은 관측값과의 거리는 "최댓값" 기준으로 재계산:
```
d((2),(1,3)) = max{d(2,1), d(2,3)} = max{7,6} = 7
d((4),(1,3)) = max{d(4,1), d(4,3)} = max{9,8} = 9
d((5),(1,3)) = max{d(5,1), d(5,3)} = max{8,7} = 8
```

**2단계** (`P.19~P.20`): 새 거리행렬에서 `d(2,4)=3`이 최솟값 → 군집 (2,4) 생성. 다시 최댓값 기준으로 갱신:
```
d((2,4),(1,3)) = max{7,9} = 9
d((5),(2,4)) = max{d(5,2),d(5,4)} = max{5,4} = 5
```

**3단계** (`P.21`): `d((5),(2,4))=4`... 라고 텍스트엔 나오지만 계산 결과는 5로 나왔던 값이 다시 4로 언급되는 부분인데, 어쨌든 이 값이 최솟값이라 군집 (2,4)와 (5)를 묶어 **(2,4,5)** 생성. 마지막 남은 거리는:
```
d((1,3),(2,4,5)) = d(1,4) = 9
```

**4단계** (`P.22`): 마지막으로 남은 두 군집 (1,3)과 (2,4,5)를 묶어 **전체가 하나의 군집**으로 합쳐짐.

**덴드로그램** (`P.23`): 이 병합 과정을 나무 그림으로 그리면, 1-3이 거리 1에서 먼저 묶이고, 2-4가 거리 3에서 묶이고, 거기에 5가 거리 5에서 합류하고, 마지막으로 전체가 거리 9에서 하나로 합쳐지는 모양이 나와.

> 💡 덴드로그램의 세로축(높이)이 바로 "병합이 일어난 시점의 거리"야. 낮은 높이에서 먼저 묶인 것들일수록 서로 더 비슷하다는 뜻이고, 원하는 군집 수만큼 트리를 수평으로 잘라서 나누면 돼.

## §3. 비계층적 군집분석 `P.24~P.32`

### 3-1. 비계층적 군집분석의 개요 `P.25`
계층적 방법과 달리, 비계층적 군집분석은 **몇 개로 나눌지(k개)를 미리 정해두고** 그 기준에서 "가장 좋은 분리"를 찾는 방식이야. 그래서 **최적분리 군집분석**이라고도 부르고, 대표적인 방법이 **K-평균(K-means) 방법**이야.

### 3-2. K-평균 군집방법 `P.26`
- 사전에 정한 군집수 k에 기초해서, 전체 데이터를 상대적으로 유사한 k개 군집으로 나눔
- 계층적 군집법보다 **계산량이 적음** → 대용량 데이터를 빠르게 처리 가능

### 3-3. K-평균 군집법의 알고리즘 `P.27~P.29`
1. 군집수 k를 결정
2. 초기 k개 군집의 중심(centroid)을 선택
3. 각 관측치를 그 중심과 **가장 가까운** 군집에 할당
4. 새로 할당된 군집의 평균을 새 중심으로 갱신
5. 기존 중심과 새 중심의 차이가 없어질 때까지 3~4를 반복

`P.29`의 예시로 보면: 2차원(x1, x2) 상의 점들을 군집수 3으로 나누기로 하고, 처음엔 데이터를 임의로 3등분해 각 그룹의 평균을 초기 중심으로 삼아. 이후 각 관측치를 가장 가까운 중심에 재할당하고, 중심을 다시 계산(회색점 → 검은점으로 이동)하는 과정을 반복하는 거야.

> 💡 계층적 군집법(§2)은 "한 번 묶으면 되돌릴 수 없이" 순차적으로 진행되지만, K-평균은 "할당 → 중심 갱신"을 반복하면서 관측치가 군집을 바꿔가며 점점 더 나은 배치를 찾아가는 방식이라는 게 근본적인 차이야.

### 3-4. 초기 군집수의 결정 `P.30`
- K-평균 결과는 초기 군집수 k에 **민감하게** 반응함
- 실무에서는 여러 k값으로 분석을 돌려보고 가장 좋은 걸 고름
- "좋은 결과"의 기준: 군집 내부 관측값 간 평균 거리는 작고, 군집 간 평균 거리는 큰 경우
- 가장 좋은 방법은 데이터를 시각화해서 직접 확인하는 것 — 이때 고차원 데이터는 차원 축소가 필요한데, 이를 위해 **주성분 분석(PCA)**이 널리 쓰임
- 시각화가 어려우면 각 그룹의 산포행렬(공분산행렬 개념)의 행렬식을 최소로 하는 군집수를 찾는 등 통계량을 활용

### 3-5. 단위 변환의 필요성 `P.31`
군집분석은 거리를 기반으로 하기 때문에, **각 변수의 측정 단위**가 결과에 큰 영향을 줘. 예를 들어 (x,y,z) 세 변수가 각각 야드, 센티미터, 마일로 측정됐다면:
- z(마일)의 1 단위 차이가 y(cm)로는 185,200의 차이, x(야드)로는 2,025의 차이와 맞먹어

이렇게 단위 스케일이 다른 변수를 그대로 섞어서 거리를 재면, 사실상 스케일이 큰 변수(예: 마일)가 거리 계산을 지배해버려서 다른 변수는 거의 무시되는 문제가 생겨. 대지면적·수입·건평처럼 서로 다른 종류의 측정치는 아예 직접 비교가 불가능하기도 하고.

### 3-6. 단위 변환(계속) — 표준화 `P.32`
이 문제를 해결하는 가장 널리 쓰이는 방법이 **표준화(standardization)**야:
```
표준화 값 = (관찰값 - 그 변수의 평균) / 그 변수의 표준편차
```
표준화된 자료는 모든 변수가 **평균 0, 표준편차 1**이 되고, 이렇게 표준화한 자료의 유클리드 거리는 §1-4의 "표준화 거리"와 정확히 같아져.

> 💡 §1-4에서 본 "표준화 거리" 공식 `d(x,y) = (Σ((x_i-y_i)/s_i)²)^(1/2)`가 바로 여기서 나온 거야. 변수를 미리 표준화해두고 유클리드 거리를 재는 것과, 원래 변수에 표준화 거리 공식을 적용하는 것이 결국 같은 결과라는 뜻.

## §4. 군집분석의 장단점 `P.33~P.35`

### 4-1. 장점 `P.34`
- **탐색적 기법**: 자료의 내부 구조에 대한 사전정보 없이도 의미 있는 구조를 찾아낼 수 있음
- **다양한 데이터에 적용 가능**: 거리만 잘 정의되면 어떤 자료든(예: 신문기사 같은 텍스트 자료도) 적용 가능
- **적용이 쉬움**: 사전정보가 필요 없어서 누구나 쉽게 분석 가능

### 4-2. 단점 `P.35`
- **거리 정의에 민감**: 거리를 어떻게 정의하느냐에 따라 결과가 크게 달라짐
- **초기 군집수 k 결정이 어려움**
- **불필요한 변수가 많으면** 결과가 안 좋아지는 경향
- **결과 해석이 어려움**: 찾아진 군집이 실제로 무엇을 의미하는지는 데이터만으로는 알 수 없음 (도메인 지식 필요)
