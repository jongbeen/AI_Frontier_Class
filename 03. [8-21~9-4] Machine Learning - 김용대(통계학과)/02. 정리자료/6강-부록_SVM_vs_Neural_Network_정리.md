## §1. Neural Network Architecture — 기본 개념 `P.2`

### 1-1. 인공신경망이란? `P.2`
인공신경망(Artificial Neural Network)은 기계학습의 한 방법인데, 이름 그대로 우리 뇌 속 신경세포(뉴런)가 신호를 주고받는 방식을 수학적으로 흉내 낸 모형이야. 뉴런은 수상돌기로 신호를 받아서 세포체에서 처리하고, 축삭을 통해 다음 뉴런한테 신호를 넘기지. 이걸 그대로 옮기면 "입력을 받아서(input layer) → 가중치를 곱해 처리하고(hidden layer) → 결과를 내보낸다(output layer)"는 구조가 돼.

> 💡 뉴런의 시냅스에서 신호가 어떤 세기로 전달되느냐가 "가중치(weight)"에 해당한다고 보면 이해가 쉬워.

**인공신경망의 역사** (알아두면 좋은 타임라인):
- **1943년** McCulloch & Pitts — 뉴런을 처음 수학적으로 모델링한 MP-model
- **1957년** Rosenblatt — 은닉층 없는 single layer perceptron
- **1986년** Rumelhart — 여러 층을 쌓은 multilayer perceptron (역전파 알고리즘 등장)
- **2006년** Hinton — 학습이 잘 안 되던 문제를 푸는 혁신적 방법(Pre-training) 개발 → 이게 지금 "딥러닝" 열풍의 시작점이야 (§4에서 자세히 다룸)

## §2. 은닉층 1개짜리 Neural Network의 수식 `P.3~P.4`

### 2-1. 기본 수식 구조 `P.3`
은닉층이 1개(K개의 출력 노드를 가진) 신경망은 이렇게 두 단계로 계산돼:

```
z_m^(0) = b_m^(0) + x^T w_m^(0),   h_m = σ(z_m^(0)),   m = 1,...,M
z_k^(1) = b_k^(1) + h^T w_k^(1),   f_k(x) = g_k(z^(1)),   k = 1,...,K
```

말로 풀면:
1. 입력 `x`(변수들)에 가중치 `w`를 곱하고 절편 `b`를 더한 값이 `z`(선형결합)
2. `z`를 활성함수 `σ`에 통과시킨 값이 은닉층 노드 `h` (이게 "뉴런이 활성화되는 정도")
3. 은닉층 값 `h`를 다시 가중치로 조합해서 `z^(1)`을 만들고, 출력함수 `g_k`를 통과시키면 최종 예측값 `f_k(x)`

> 💡 회귀분석에서 "여러 변수를 가중합해서 예측값을 만드는 것"과 근본적으로 비슷한데, 신경망은 그 과정을 한 번 더(은닉층을 거쳐서) 반복한다고 보면 돼.

**σ(활성함수)**: 보통 sigmoid나 tanh를 쓴다.
- `σ_sig(v) = 1/(1+e^(-v))`
- `σ_tanh(v) = (e^v - e^(-v))/(e^v + e^(-v))`

**g_k(출력함수)**: 문제 유형에 따라 다르게 씀
- 회귀분석: `g_k(t) = t` (그냥 그대로 출력)
- 분류문제: softmax 함수 `g_k(t) = e^(t_k) / Σ e^(t_l)` (여러 클래스 중 확률처럼 정규화)

### 2-2. 활성함수 그래프 — Sigmoid vs Tanh `P.4`
- **Sigmoid**: `f(x) = 1/(1+e^(-x))` — 출력이 0~1 사이. 큰 음수는 0에, 큰 양수는 1에 수렴하는 S자 곡선.
- **Tanh**: `tanh(x) = 2/(1+e^(-2x)) - 1` — 출력이 -1~1 사이. 모양은 sigmoid와 비슷하지만 원점을 중심으로 대칭이라는 게 차이야.

> 💡 두 함수 다 "입력이 아주 크거나 작으면 출력이 거의 안 바뀌는" 평평한 구간이 있어. 이 부분이 나중에(§4) 학습이 잘 안 되는 원인(vanishing gradient)의 핵심이 돼.

## §3. 딥러닝과 Fully Connected NN 구조 `P.5~P.7`

### 3-1. 딥러닝이란? `P.5`
**딥러닝 = 은닉층이 2개 이상인 신경망 모형**. 정의가 생각보다 단순해. "Non-deep" NN은 은닉층이 1개뿐이고, Deep Neural Network는 은닉층을 여러 개(hidden layer 1, 2, 3...) 겹겹이 쌓은 구조야. 층이 깊어질수록 더 복잡한 패턴을 표현할 수 있다는 게 기본 아이디어지.

### 3-2. L개의 은닉층을 가진 구조 `P.6~P.7`
표기법부터 정리하면, `h^(l)` (l = 0,...,L+1)을 l번째 층의 노드값이라 하자. 이때 `h^(0) = x`(입력층 자체), `h^(L+1) = f(x)`(최종 출력)로 정의해. 즉 입력도 출력도 "층"의 하나로 취급하는 거야.

각 층 사이의 계산은 다음과 같이 반복돼 (`P.7`):

```
z_j^(l+1) = b_j^(l) + Σ_s w_sj^(l) h_s^(l),    l = 0,...,L
h_j^(l+1) = σ(z_j^(l+1)),                       l = 0,...,L-1   (은닉층)
f_j(x) = h_j^(L+1) = g(z_j^(L+1))                              (출력층)
```

즉, **같은 계산(가중합 → 활성함수)을 층마다 반복해서 앞으로 밀고 나가는 것**이 fully connected 신경망의 전부야. 은닉층까지는 활성함수 σ를 쓰고, 마지막 출력층에서만 출력함수 g를 쓰는 게 유일한 차이점.

> 💡 §2에서 본 "은닉층 1개짜리" 수식과 사실 똑같은 구조야. 그냥 그 과정을 L번 반복해서 층을 깊게 쌓은 것뿐이라고 생각하면 이해가 쉬워.

## §4. Neural Network 흥망성쇠 `P.8~P.11`

### 4-1. 2006년 이전 DNN의 문제 ① — Vanishing gradients & 계산 시간 `P.8`
**Vanishing gradients problem**: 역전파(backpropagation) 알고리즘으로 층을 거슬러 올라가며 가중치를 업데이트하는데, 층이 깊어질수록 이 업데이트 신호(gradient)가 점점 작아져서 거의 0에 가까워져 버려. 그 결과:
- 최적의 해가 아니라 지역해(local minima)에 갇히는 경우가 잦았고,
- 오히려 은닉층 1개짜리 얕은 신경망보다 성능이 더 나쁜 경우도 발생했어.

**Running time 문제**: 층이 많으면 추정해야 할 모수(가중치)의 개수가 훨씬 많아지고, 그만큼 학습 시간도 오래 걸려. 당시 컴퓨팅 파워로는 감당하기 어려웠던 거지.

→ 결과적으로 실무에서는 **은닉층 하나짜리 얕은 신경망**이 주로 쓰였어.

### 4-2. 2006년 이전 DNN의 문제 ② — "어차피 얕은 것도 충분하다" `P.9`
Cybenko(1989)의 **Universal Approximation Theorem**이 이론적으로 뒷받침해준 사실: sigmoid 활성함수를 쓰는 은닉층 1개짜리 신경망만으로도, 유한한 개수의 노드를 합쳐서(`G(x) = Σ α_j σ(y_j^T x + θ_j)`) 어떤 연속함수든 원하는 정밀도(ε)만큼 근사할 수 있다는 정리야.

> 💡 즉 "이론적으로는 층을 깊게 쌓지 않아도, 은닉층 하나만 충분히 넓게(노드를 많이) 만들면 뭐든 표현할 수 있다"는 뜻이야. 그러니 굳이 학습이 어려운 깊은 신경망을 쓸 이유가 없었던 거지.

### 4-3. 2006년 이전 DNN의 문제 ③ — NN vs SVM 비교에서 밀림 `P.10`
신경망의 커널을 `K(x1,x2) = tanh(κ1 x1^T x2 + κ2)`로 볼 수 있는데, κ1=1, κ2=0으로 두면:
- **SVM(커널머신)의 추정식**: `f̂(x) = β0 + Σ βi tanh(xi^T x)`
- **은닉층 1개 신경망의 추정식**: `f̂(x) = β0 + Σ βi tanh(αk^T x)`

두 식이 형태상 거의 똑같아 보이지? 그런데 결정적인 차이가 하나 있어: **SVM은 볼록(convex) 최적화 문제라서 항상 전역 최적해를 찾을 수 있는 반면, NN은 convex가 아니라서(non-convex) 지역해에 빠질 위험이 있어.**

> 💡 "같은 표현력을 낼 수 있는데 한쪽은 항상 정답을 찾아주고, 한쪽은 운이 나쁘면 엉뚱한 데서 멈춘다"면 당연히 안정적인 쪽(SVM)을 선호하겠지. 이게 바로 1990년대~2000년대 초 학자들이 신경망을 외면한 이유야.

### 4-4. 부활의 계기 — Pre-training `P.11`
2006년 **G.E. Hinton 교수**가 이 문제를 뒤집는 아이디어를 제안했어.

- **기존 역전파 알고리즘의 문제**: 최종 결과가 처음에 어떤 초기값에서 출발하느냐에 크게 좌우되는데, 좋은 초기값을 미리 알기가 어려웠음.
- **Hinton의 아이디어(Pre-training)**: 정답 레이블 없이 **입력 변수만 가지고 먼저 모수를 대략 추정**해두고, 이 추정값을 역전파의 **초기값**으로 사용하는 방법.

이렇게 "아무렇게나 초기화"가 아니라 "데이터 구조를 반영한 괜찮은 출발점"에서 시작하니 지역해 문제가 크게 줄었고, 이게 바로 **딥러닝이 폭발적으로 발전하게 된 결정적 전환점**이 됐어.

## 한눈에 보는 핵심 정리표

| 구분 | 얕은 신경망 (1개 은닉층) | SVM | 깊은 신경망 (Deep NN, 2006년 이후) |
|---|---|---|---|
| 최적화 문제 | Non-convex (지역해 위험) | Convex (전역해 보장) | Non-convex이지만 Pre-training으로 완화 |
| 표현력 | Universal Approximator (이론상 충분) | 커널 방식으로 비선형 표현 | 층이 깊어 더 복잡한 패턴 표현 가능 |
| 초기값 문제 | 역전파 결과가 초기값에 좌우됨 | 해당 없음(convex라 무관) | Pre-training으로 좋은 초기값 확보 |
| 계산 비용 | 상대적으로 적음 | 데이터 수에 따라 증가 | 모수 많아 계산량 큼(당시 병목) |
| 2000년대 초 인기 | 그나마 실무에서 사용됨 | 우세(안정적 학습) | 외면받음 → 2006년 이후 부활 |
