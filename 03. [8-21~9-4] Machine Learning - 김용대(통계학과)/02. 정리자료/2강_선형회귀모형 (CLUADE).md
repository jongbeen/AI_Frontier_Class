## 1. 선형회귀모형

### 1-1. 회귀분석이란? (p.4)

**회귀분석**은 "입력값을 넣으면 출력값이 얼마나 나올지"를 예측하는 함수를 데이터로부터 찾아내는 방법입니다.

- 모형: `Y = f(X) + ε`
  - `Y`: 우리가 맞히고 싶은 결과값 (예: 난방비)
  - `X`: 결과에 영향을 주는 입력값 (예: 온도)
  - `ε` (엡실론): 모형이 설명하지 못하는 오차(noise)
- 가진 데이터: `(y₁,x₁), ..., (yₙ,xₙ)` — 즉 n개의 (결과, 입력) 짝
- **목적**: 이 데이터만 보고 `f`라는 함수를 추정하는 것

👉 쉽게 말해: "입력(X) → 시스템(f) → 출력(Y)" 구조에서, 우리가 가진 건 입력과 출력 데이터뿐이고, 그 사이의 관계식(f)을 역으로 알아내는 것이 회귀분석입니다.

### 1-2. 선형회귀모형 (p.5)

`f`가 **직선(또는 평면) 형태**라고 가정하면 그것이 선형회귀모형입니다.

- `Y = xᵀβ + ε`
- `β = (β₁, β₂, ..., βₚ)ᵀ` : 우리가 구해야 할 **회귀계수**(직선의 기울기 같은 값들)

> 참고로 `Y = sin(2x) + ε` 처럼 곡선 형태면 비선형회귀모형이라고 부릅니다. 이 강의는 직선(선형) 관계에 집중합니다.

### 1-3. 최소제곱추정 — β를 어떻게 구할까? (p.6)

가장 널리 쓰이는 방법이 **최소제곱법(Least Squares)** 입니다.

- 아이디어: 실제 관측값 `yᵢ`와 모형이 예측한 값 `xᵢᵀβ`의 차이(오차)를 제곱해서 다 더한 값이 **최소가 되는 β**를 찾는다.

$$\hat\beta = \underset{\beta}{\text{argmin}} \sum_{i=1}^n (y_i - x_i^Tβ)^2$$

👉 그래프로 보면, 각 점에서 직선까지의 세로 거리(오차)를 제곱해서 합한 게 가장 작아지도록 직선을 긋는 것입니다. 1806년 Legendre가 제안한 방법으로, 지금도 회귀분석의 기본입니다.

### 1-4. 예측과 해석 (p.7)

- **예측**: 새로운 입력 `x`가 주어지면 `ŷ = xᵀβ̂` 로 결과를 예측합니다.
- **해석**: 계수 `βⱼ`는 "다른 조건이 같을 때, `xⱼ`가 1단위 증가하면 `y`가 얼마나 변하는지"를 의미합니다.
  - `βⱼ > 0` → `xⱼ`가 커지면 `y`도 커짐 (양의 관계)
  - `βⱼ < 0` → `xⱼ`가 커지면 `y`는 작아짐 (음의 관계)

### 1-5. 실전 예제: 아파트 난방비 (p.8~10)

**문제 상황 (p.8)**: A건설회사가 20개 아파트를 조사해서, 아래 3가지 입력변수로 겨울 난방비(Y)를 예측하려고 합니다.
1. 겨울 평균온도
2. 방열재 두께
3. 아파트 나이

**회귀계수 추정 결과 (p.9)**

| 입력변수 | 회귀계수 | 표준오차 | T | 유의확률 |
|---|---|---|---|---|
| 절편 | 427.19 | 59.60 | 7.17 | 0.000 |
| 온도 | -4.5827 | 0.7723 | -5.93 | 0.000 |
| 방열재 | -14.831 | 4.754 | -3.12 | 0.007 |
| 나이 | 6.101 | 4.012 | 1.52 | 0.148 |

**최종 회귀식과 해석 (p.10)**

`Y = 427 − 4.58·X₁ − 14.80·X₂ + 6.10·X₃`

- 평균온도가 1도 **떨어지면** 난방비 4.58단위 **증가**
- 방열재 두께가 1단위 **증가하면** 난방비 14.80단위 **감소**
- 아파트 나이가 1년 **증가하면** 난방비 6.10단위 **증가**

> 팁: 계수 부호만 보면 "관계의 방향"을 바로 알 수 있습니다. 온도·방열재는 음수(반비례), 나이는 양수(비례)입니다.

## 2. 선형로지스틱회귀모형

### 2-1. 왜 필요한가? (p.11~12)

앞의 선형회귀는 `Y`가 연속된 숫자(예: 난방비)일 때 씁니다. 하지만 `Y`가 **범주형(예/아니오, 성공/실패)** 이면 다른 방법이 필요합니다. 이때 쓰는 대표적인 모형이 **로지스틱 회귀모형**입니다.

- `Y = 1`: 결과가 첫 번째 범주 (예: "합격")
- `Y = 0`: 결과가 두 번째 범주 (예: "불합격")
- 목적: 입력변수로 "`Y=1`일 확률"을 예측하는 것

### 2-2. 모형의 구조 (p.13~14)

`P(Y=1|X) = F(Xᵀβ)`

여기서 `F(x)`는 값이 항상 0~1 사이가 되도록 만드는 함수입니다. (확률이니까요!) 여러 후보가 있지만:

- **로지스틱 함수** (가장 널리 씀, 계산이 편함): `F(x) = exp(x) / (1+exp(x))`
- 곰페르츠(Gompertz) 모형, 프로빗(Probit) 모형도 있음

**로지스틱회귀모형 최종 식 (p.14)**

$$P(Y=1|X=x) = \frac{\exp(x^Tβ)}{1+\exp(x^Tβ)}$$

이 식을 변형하면:

$$\log\frac{P(Y=1|X=x)}{P(Y=0|X=x)} = x^Tβ$$

👉 즉, **확률 자체는 곡선(S자 모양)이지만, "로그 오즈(log-odds)"는 선형**입니다. 이게 로지스틱 회귀의 핵심 트릭입니다.

### 2-3. β는 어떻게 구하나? — 최대가능도추정 (p.15)

선형회귀는 최소제곱법을 썼지만, 로지스틱 회귀는 **최대가능도추정(MLE)** 을 씁니다.

- 가능도함수 `L(β)`: 지금 가진 데이터가 나올 "가능성(확률)"을 β의 함수로 표현한 것
- 이 가능도가 **최대**가 되는 β를 찾음
- 직선처럼 딱 떨어지는 공식이 없어서, **Newton-Raphson** 같은 수치적(반복 계산) 방법으로 구합니다.

### 2-4. 예측과 해석 (p.16)

- `P̂(Y=1|X=x) > 0.5` → 1로 예측
- `P̂(Y=1|X=x) < 0.5` → 0으로 예측
- `β₁ > 0`: x가 커지면 Y=1일 확률도 커짐
- `β₁ < 0`: x가 커지면 Y=1일 확률은 작아짐

### 2-5. 오즈(odds)와 오즈비(odds ratio) (p.17~18)

이 부분이 로지스틱 회귀 해석의 핵심이라 조금 더 자세히 풀어볼게요.

- **오즈(odds)**: "성공확률 ÷ 실패확률" → `odds(x) = P(Y=1|x) / P(Y=0|x)`
  - 예: 성공확률이 80%면 오즈는 0.8/0.2 = 4 (성공이 실패보다 4배 더 자주 일어남)
- **오즈비(odds ratio)**: x가 1단위 증가할 때 오즈가 몇 배가 되는지
  - 중요한 성질: **오즈비(x) = exp(β)**

**예시 해석 (p.18)**: x=소득, y=구매여부, 회귀계수 β=3.72라면
→ `exp(3.72) ≈ 42`
→ "소득이 1단위 오르면, 안 살 확률 대비 살 확률의 비율이 **42배**로 커진다"는 뜻입니다.

👉 정리하면: **β 자체는 로그 오즈의 기울기**이고, **exp(β)는 오즈가 몇 배로 뛰는지**를 알려주는 값입니다.

### 2-6. 실전 예제: 회사채 신용등급 (p.19~23)

**문제 상황 (p.19)**: 회사채 신용등급(안정=1, 위험=0)을 재무자료로 예측

- x1: 자산대비 부채비율
- x2: 현금회전율
- x3: 종업원 수 (범주형: 50인 이하 / 50~100인 / 100인 이상)

**가변수(더미변수) 처리 (p.20)**

x3는 숫자가 아니라 **범주**이기 때문에 그대로 넣을 수 없고, 가변수(dummy variable) z1, z2로 바꿔줍니다.

| 구분 | z1 | z2 |
|---|---|---|
| 50인 이하 | 0 | 0 |
| 50~100인 | 1 | 0 |
| 100인 이상 | 0 | 1 |

**회귀계수 추정 결과 (p.21)**

| 입력변수 | 회귀계수 | 표준오차 | Chi-square | 유의확률 |
|---|---|---|---|---|
| Intercept | 12.2216 | 3.5942 | 11.5623 | 0.000 |
| X1 | -1.0727 | 0.3933 | 7.4389 | 0.006 |
| X2 | 11.5243 | 4.1313 | 7.7814 | 0.005 |
| X3-1 | 0.6981 | 0.3571 | 3.9404 | 0.047 |
| X3-2 | 2.6141 | 0.7915 | 10.9078 | 0.001 |

**결과 해석 (p.22~23)**

- X1(부채비율) 계수가 **음수** → 부채비율이 높을수록 신용등급이 낮아짐
- X2(현금회전율) 계수가 **양수** → 현금회전율이 높을수록 신용등급이 좋아짐
- X3-1 (50~100인 vs 50인 이하): `exp(0.6981) ≈ 2.00` → 50~100인 규모 회사가 50인 미만보다 신용이 **약 2배** 좋음
- X3-2 (100인 이상 vs 50인 이하): `exp(2.6141) ≈ 13.65` → 100인 이상 규모 회사가 50인 미만보다 신용이 **약 13.65배** 좋음

## 3. 변수선택

### 3-1. 왜 변수를 선택해야 하나? (p.25~26)

현실에서는 입력변수(X)가 아주 많은데, 그중 정말로 Y에 영향을 주는 변수는 소수인 경우가 많습니다.

**변수선택이 필요한 이유**
- 변수가 너무 많으면 관리 비용·계산 비용이 큼
- 불필요한 변수를 빼고 적절한 복잡도를 유지하면 예측 오차가 줄어듦
- ⚠️ 다만 중요한 변수를 빼버리면 정보 손실 + 결과가 편향(왜곡)될 수 있음 → 무작정 줄이는 게 능사는 아님

### 3-2. 단순한 방법의 함정: 다중공선성 (p.27~32)

**단변량 방법의 문제 (p.27)**: "각 x와 y의 상관계수를 각각 구해서, 상관계수 큰 순서대로 변수를 뽑는다"는 방식은 **다중공선성(multicollinearity)** 때문에 잘못된 선택을 할 수 있습니다.

**다중공선성이란?** 입력변수들끼리 서로 상관되어 있어서, 변수를 하나씩 따로 볼 때와 여러 개를 같이 볼 때 결과가 달라지는 현상입니다.

**예제: 월소득·가구원수 → 월저축액 (p.28~29)**

| 분석 방식 | 월소득 계수 | 가구인원수 계수 |
|---|---|---|
| 단변량(각각 따로) | 0.205 (유의함) | 1.625 (유의하지 않음, p=.206) |
| 다변량(같이 넣음) | 0.301 | **-2.091** (유의함, 부호가 반대로 바뀜!) |

👉 가구원수만 따로 보면 "저축액과 관계없다"는 결론이 나오지만, 월소득을 같이 고려하면 오히려 "가구원수가 늘수록 저축액이 줄어든다"(음수)는 정반대 결론이 나옵니다. 이것이 다중공선성의 함정입니다.

**심슨의 역설(Simpson's Paradox) — 버클리대 입학 사례 (p.30~31)**

| | 합격 | 불합격 | 지원자 계 |
|---|---|---|---|
| 남자 | 1400(52%) | 1291(48%) | 2691 |
| 여자 | 772(42%) | 1063(58%) | 1835 |
| 전체 | 2172(48%) | 2354(52%) | 4526 |

전체만 보면 남자 합격률(52%)이 여자(42%)보다 높아 **성차별 의혹**이 제기됐습니다.

하지만 **학과별로 쪼개서 보면**:

| 분야 | 남자 지원자/합격률 | 여자 지원자/합격률 |
|---|---|---|
| A | 825 / 62% | 108 / 82% |
| B | 560 / 63% | 25 / 68% |
| C | 325 / 37% | 593 / 34% |
| D | 417 / 33% | 375 / 35% |
| E | 191 / 28% | 393 / 24% |
| F | 373 / 60% | 341 / 70% |

→ 대부분 학과에서 오히려 **여자 합격률이 더 높거나 비슷**합니다. (여자 지원자가 합격률 낮은 학과에 많이 몰렸을 뿐) 즉 **성차별 주장은 틀렸다**는 결론입니다.

👉 교훈: **전체 합계만 보고 판단하면 숨겨진 변수(분야) 때문에 결론이 완전히 뒤집힐 수 있습니다.** 이래서 변수를 하나씩만 보지 않고 여러 변수를 같이 고려하는 다변량 분석이 중요합니다.

### 3-3. 후보 모형을 만드는 방법들 (p.33~35)

**모형 선택 절차 (p.33)**: ① 다양한 복잡도의 후보 모형들을 만든다 → ② 그중 최적 모형을 고른다

**후보 모형 생성 방법 (p.34)**

| 방법 | 설명 |
|---|---|
| All possible method | 가능한 모든 변수 조합을 다 시도 (가장 확실하지만 변수 많으면 계산량 폭발) |
| **전진선택법 (Forward selection)** | 변수 0개에서 시작해서 하나씩 추가 |
| 후진소거법 (Backward elimination) | 모든 변수를 넣고 하나씩 제거 |
| 단계적 방법 (Stepwise) | 추가·제거를 번갈아 수행 |

**최적 모형 판단 기준 (p.35)**

- **AIC** = `−log(가능도) + 2k` (k = 선택된 변수 개수) → 작을수록 좋은 모형
- **BIC** = `−log(가능도) + (log n)k` → 데이터 개수(n)가 많을 때 변수 추가에 더 엄격한 벌점을 줌

👉 두 기준 모두 "설명력은 높이되, 변수를 불필요하게 많이 쓰면 벌점을 준다"는 공통 철학입니다.

### 3-4. 실전 예제: 와인 품질 예측 (전진선택법 + AIC) (p.36~44)

**데이터 소개 (p.36~37)**: Red wine 1599개, 물리화학적 측정값 11개(산도, 알콜량, 당도 등)로 **Quality(0~10점, 관능평가)** 를 예측

**1단계: 변수 1개씩 넣어보기 (p.38~40)**

| 변수 | AIC |
|---|---|
| Fixed acidity | -705.29 |
| pH | -685.84 |
| Citric acid | -764.61 |
| **Alcohol** | **-1091.65** ← 최소, 선택! |
| Residual sugar | -680.80 |
| ... | -682.50 |

→ AIC가 가장 작은 **Alcohol** 선택 (현재 모형 AIC = -1091.65)

**2단계: Alcohol에 하나씩 추가해보기 (p.41~42)**

| 추가 변수 | AIC |
|---|---|
| Fixed acidity | -1139.3 |
| pH | -1142.8 |
| Citric acid | -1154.3 |
| **Residual sugar** | **-1288.1** ← 최소, 선택! |
| ... | -1090.3 |

→ **Residual sugar** 추가 (현재 모형 AIC = -1288.1)

**3단계: 더 추가해도 나아지는가? (p.43)**

| 추가 후보 변수 | AIC |
|---|---|
| Fixed acidity | -1239.3 |
| pH | -1232.8 |
| Citric acid | -1254.3 |
| ... | -1242.3 |

→ 모두 현재 모형(-1288.1)보다 **AIC가 더 큼(=더 나쁨)** → 추가 중단

**최종 모형 (p.44)**: `Alcohol + Residual sugar` (AIC = -1288.1)

### 3-5. 전진선택법의 장단점 (p.45)

| 장점 | 단점 |
|---|---|
| 이해하기 쉬움 | 최적 모형을 놓칠 수 있음 |
| 변수가 많아도 사용 가능 | 데이터의 작은 변동에도 결과가 크게 바뀜 |
| | 한 변수가 뽑히면, 그와 상관관계 큰 변수는 못 뽑힘 |
| | "**Usually overly greedy**" (매 단계 눈앞의 최선만 보는 탐욕적 알고리즘의 한계) |

## 한눈에 보는 핵심 요약

| 구분 | 언제 쓰나 | 계수 추정법 | 핵심 결과 해석 |
|---|---|---|---|
| **선형회귀** | Y가 연속값(숫자) | 최소제곱법 | β = X 1단위 증가시 Y의 변화량 |
| **로지스틱회귀** | Y가 범주(0/1) | 최대가능도추정 | exp(β) = 오즈비 (오즈가 몇 배 되는지) |
| **변수선택** | 입력변수가 많을 때 | 전진선택법 + AIC/BIC | AIC가 최소인 조합을 채택 |

**꼭 기억할 것**: 변수를 하나씩 따로 보지 말고 같이 봐야 한다 (다중공선성, 심슨의 역설). 그리고 변수를 무조건 많이 넣는 게 아니라, AIC/BIC 같은 기준으로 "적당히" 골라야 한다.
