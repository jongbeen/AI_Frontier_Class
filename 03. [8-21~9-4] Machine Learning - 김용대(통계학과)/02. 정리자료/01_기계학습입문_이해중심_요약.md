## 0. 전체 흐름

**기계학습 → 지도학습 → 선형모형과 k-NN → 좋은 예측모형 → 차원의 저주 →
과적합 → Bias-Variance Trade-off**

핵심 질문은 하나다.

> **주어진 데이터에서 규칙을 학습해, 처음 보는 데이터의 결과를 얼마나 잘
> 예측할 수 있는가?**

## 1. 기계학습이란?

### 전통적인 학습

1.  관측이나 직관을 바탕으로 가설을 세운다.
2.  실험 및 통계추론을 한다.
3.  결론을 도출한다.

### 기계학습

1.  데이터를 모은다.
2.  데이터를 분석한다.
3.  데이터에서 새로운 지식이나 규칙을 찾는다.

**핵심 표현:** `Let the data tell something.`

즉, 사람이 모든 규칙을 미리 정하는 것이 아니라 **데이터에서 패턴을
학습하도록 하는 것**이 핵심이다.

### 왜 필요한가?

-   현실의 문제는 매우 복잡하다.
-   변수 사이에 단순하지 않은 관계가 존재한다.
-   세상이 빠르게 변한다.
-   IT 기술 발달로 데이터가 빠르게 증가한다.
-   대규모 데이터에서 사람이 직접 찾기 어려운 패턴을 발견할 수 있다.

------------------------------------------------------------------------

## 2. 기계학습의 종류

### 2.1 지도학습 (Supervised Learning)

**입력변수 X를 이용하여 출력변수 Y를 예측한다.**

예: - 고객 정보를 이용한 연체 여부 예측 - 이미지의 개/고양이 분류 - 환자
정보를 이용한 질병 진단

대표적인 문제: - 회귀분석 - 분류분석

### 2.2 비지도학습 (Unsupervised Learning)

정답에 해당하는 **출력변수 Y가 없는 상태**에서 데이터 내부의 구조나
관계를 찾는다.

예: - 군집분석 - 주성분분석 - 차원축소 - 이미지 압축/생성

### 2.3 강화학습 (Reinforcement Learning)

행동에 따라 환경이 변할 때 **보상을 최대화하는 의사결정 방법**을
학습한다.

예: - AlphaGo - 게임 AI - 로봇

------------------------------------------------------------------------

## 3. 지도학습의 기본 구조

지도학습을 가장 간단하게 표현하면 다음과 같다.

`입력 X → 예측모형 f → 출력 Y 예측`

### Input (X)

예측에 사용하는 정보.

예: - 나이 - 소득 - 신용점수 - 대출금액

### Output (Y)

최종적으로 맞히고 싶은 값.

예: - 연체 여부 - 집값 - 매출액

### Training Data

이미 X와 Y를 알고 있는 과거 데이터.

이 데이터를 이용하여 예측모형 `f`를 학습한다.

### 새로운 데이터 예측

새로운 입력값 `x_new`가 들어오면 학습한 모형을 이용해 아직 모르는
`y_new`를 예측한다.

------------------------------------------------------------------------

## 4. Regression과 Classification

### Regression (회귀)

Y가 **연속적인 숫자**인 경우.

예: - 집값 - 매출 - 온도 - 소비금액

### Classification (분류)

Y가 **범주형 값**인 경우.

예: - 정상 / 연체 - 개 / 고양이 - 스팸 / 정상메일

### 기억하기

> **숫자 예측 → Regression**\
> **종류 예측 → Classification**

------------------------------------------------------------------------

## 5. 선형모형 (Linear Model)

선형모형은 변수 사이의 관계를 **직선 형태로 가정**한다.

대표적인 형태:

`f(x) = β0 + β1x1 + β2x2 + ... + βpxp`

여기서 β는 각 입력변수가 결과에 얼마나 영향을 주는지를 나타내는 계수라고
이해하면 된다.

### 예시

`집값 = 기본가격 + 평수 × 계수`

와 같이 설명할 수 있다.

### 장점

-   구조가 단순하다.
-   결과를 해석하기 쉽다.
-   비교적 적은 데이터에서도 사용할 수 있다.

### 단점

실제 관계가 비선형이면 예측력이 떨어질 수 있다.

------------------------------------------------------------------------

## 6. k-NN (k-Nearest Neighbor)

k-NN의 핵심 아이디어:

> **새로운 데이터와 가장 비슷한 과거 데이터 k개를 찾아 그 결과를
> 이용한다.**

회귀 문제에서는 가까운 k개 관측치의 Y값 평균을 이용할 수 있다.

### 예시

새로운 고객과 가장 비슷한 고객 5명의 소비금액이

`100 / 120 / 110 / 90 / 130만원`

이라면 평균인 **110만원** 정도로 예측한다.

### k의 의미

`k = 참고할 이웃의 개수`

#### k가 작을 때

-   주변 데이터를 매우 세밀하게 따라간다.
-   모형이 복잡해진다.
-   데이터의 잡음에도 민감해질 수 있다.

#### k가 클 때

-   많은 데이터의 평균을 사용한다.
-   모형이 단순하고 부드러워진다.
-   개별적인 특징을 놓칠 수 있다.

> **k ↓ → 복잡도 ↑**\
> **k ↑ → 복잡도 ↓**

------------------------------------------------------------------------

## 7. 선형모형 vs k-NN

  구분          선형모형                 k-NN
  ------------- ------------------------ ------------------------------
  가정          선형관계 가정            특별한 함수 형태 가정이 적음
  데이터 크기   작거나 중간이어도 가능   비교적 많은 데이터 필요
  해석          쉬움                     어려움
  비선형 관계   취약할 수 있음           비교적 유연함
  조절할 값     상대적으로 적음          k를 정해야 함

### 핵심

어떤 모형이 항상 더 좋은 것은 아니다.

-   실제 관계가 선형이면 → 선형모형이 효과적
-   실제 관계가 복잡한 비선형이면 → NN과 같은 유연한 모형이 유리할 수
    있음

------------------------------------------------------------------------

## 8. Simulation에서 알아야 할 것

강의에서는 선형 관계와 비선형 관계를 각각 만들어 선형모형과 NN을
비교한다.

### Simulation 1

실제 관계가 거의 선형:

`y = x + ε`

→ 선형모형이 잘 작동한다.

### Simulation 2

실제 관계가 비선형:

`y = x(1-x) + ε`

→ 직선만 표현하는 선형모형보다 NN이 유리해질 수 있다.

### 중요한 결론

1.  실제 데이터 구조에 따라 좋은 모형이 달라진다.
2.  복잡한 모형이 항상 좋은 것은 아니다.
3.  **Training Error만으로 모형의 실제 예측력을 판단하면 안 된다.**

------------------------------------------------------------------------

## 9. 손실함수와 좋은 예측모형

예측값과 실제값의 차이를 수치로 표현하는 것이 **손실함수(Loss
Function)**이다.

회귀에서는 대표적으로 제곱손실을 사용한다.

`Loss = (실제값 - 예측값)^2`

오차가 클수록 더 큰 손실을 부여한다.

### Expected Prediction Error (EPE)

새로운 데이터까지 고려했을 때 평균적으로 얼마나 틀리는지를 나타내는
개념.

좋은 모형은 결국 **예측오차를 최소화하는 모형**이다.

회귀에서 제곱손실을 사용할 경우 이론적으로 가장 좋은 예측값은

`E(Y | X=x)`

즉, **X=x라는 조건에서 Y의 조건부 평균**이다.

------------------------------------------------------------------------

## 10. 분류와 Bayes Rule

분류에서는 각 범주가 나타날 확률을 생각할 수 있다.

예:

`P(연체 | 고객정보)`

`P(정상 | 고객정보)`

틀린 분류에 동일한 손실을 부여한다면 **조건부 확률이 가장 높은 범주를
선택하는 것**이 최적의 분류 방법이다.

이를 **Bayes classifier / Bayes rule**이라고 한다.

### k-NN과 연결

주변 k명의 데이터 중 특정 범주가 차지하는 비율을 이용하여 조건부 확률을
추정할 수 있다.

------------------------------------------------------------------------

## 11. 차원의 저주 (Curse of Dimensionality)

k-NN은 '가까운 데이터'를 찾는 방법이다.

그런데 입력변수의 개수, 즉 **차원 p가 많아질수록 가까운 데이터를 찾기가
어려워진다.**

### 직관적 예시

변수가 하나라면:

`나이가 비슷한 사람`

을 찾으면 된다.

변수가 많아지면:

`나이 + 소득 + 직업 + 자산 + 대출 + 신용점수 + 소비패턴 + ...`

모든 조건에서 비슷한 사람을 찾기가 매우 어려워진다.

강의자료의 예에서는 10차원 공간에서 데이터의 1%를 포함하려 해도 각 변수
범위의 약 63%를 포함해야 한다.

즉, 더 이상 '가까운 지역'이라고 하기 어려워진다.

> **차원이 증가할수록 데이터 공간이 급격하게 넓어지고 데이터가
> 희소해지는 현상**

을 차원의 저주라고 이해하면 된다.

------------------------------------------------------------------------

## 12. Training Error와 Test Error

### Training Error

모형을 학습할 때 사용했던 데이터에서 계산한 오차.

### Test Error

학습에 사용하지 않은 **새로운 데이터**에서 계산한 오차.

우리가 실제로 중요하게 생각해야 하는 것은 Test Error이다.

> **Training Error가 낮다고 실제 예측력이 좋은 것은 아니다.**

------------------------------------------------------------------------

## 13. 과적합 (Overfitting)

과적합은

> **학습 데이터에는 지나치게 잘 맞지만 새로운 데이터에서는 예측력이
> 떨어지는 현상**

이다.

### 시험공부에 비유

기출문제 답을 전부 외워서

-   기출문제: 100점
-   새로운 문제: 60점

이라면 제대로 일반화한 것이 아니다.

기계학습에서도 동일하다.

모형이 지나치게 복잡하면 데이터에 포함된 **진짜 패턴뿐 아니라 우연한
잡음까지 학습**할 수 있다.

### 모형 복잡도와 Error

모형이 복잡해질수록 일반적으로:

`Training Error → 계속 감소`

하지만 Test Error는:

`감소 → 최적점 → 다시 증가`

할 수 있다.

다시 증가하는 영역이 **과적합 영역**이다.

------------------------------------------------------------------------

## 14. Bias-Variance Trade-off

예측오차를 이해하는 핵심 개념.

### Bias (편의/편향)

모형이 너무 단순해서 실제 관계를 충분히 표현하지 못하면서 발생하는 오류.

예: - 실제 관계 = 곡선 - 모델 = 직선만 표현 가능

→ Bias가 커질 수 있다.

### Variance (분산)

학습 데이터가 조금 달라졌을 때 예측모형 자체가 크게 변하는 정도.

복잡한 모형은 데이터 변화에 민감하기 때문에 Variance가 커질 수 있다.

### 일반적인 관계

`모형 복잡도 ↑ → Bias ↓ / Variance ↑`

`모형 복잡도 ↓ → Bias ↑ / Variance ↓`

따라서 가장 복잡하거나 가장 단순한 모형을 선택하는 것이 아니라 **Bias와
Variance 사이의 적절한 균형점을 찾는 것**이 중요하다.

------------------------------------------------------------------------

## 15. k-NN으로 Bias-Variance 이해하기

### k = 1

가장 가까운 관측치 하나만 사용한다.

-   매우 세밀함
-   Bias 낮음
-   Variance 높음
-   과적합 위험이 큼

### k가 커짐

여러 관측치를 평균낸다.

-   모형이 부드러워짐
-   Bias 증가
-   Variance 감소

### k = n

사실상 전체 데이터의 평균을 사용한다.

-   개별적인 X의 특징을 거의 반영하지 못함
-   Bias가 커짐
-   Variance는 작아짐

------------------------------------------------------------------------

# 16. 1강 핵심 연결 구조

``` text
기계학습
   ↓
데이터에서 패턴 학습
   ↓
지도학습
   ↓
X를 이용해 Y 예측
   ↓
┌───────────────┐
│               │
Regression   Classification
숫자 예측      범주 예측
   ↓
예측모형을 어떻게 만들까?
   ↓
Linear Model / k-NN
   ↓
복잡한 모델이 무조건 좋은가?
   ↓
아니다
   ↓
Training Error와 Test Error 구분
   ↓
너무 복잡하면 Overfitting
   ↓
Bias-Variance Trade-off
```

그리고 k-NN에서는 별도로:

``` text
입력변수(차원)가 너무 많아짐
        ↓
가까운 이웃을 찾기 어려움
        ↓
Curse of Dimensionality
```

# 17. 시험/복습용 핵심 암기

1.  **지도학습:** 입력 X를 이용하여 출력 Y를 예측한다.
2.  **Regression:** 연속적인 숫자를 예측한다.
3.  **Classification:** 범주를 예측한다.
4.  **Linear Model:** 변수 사이의 선형관계를 가정한다.
5.  **k-NN:** 새로운 데이터와 가까운 k개의 데이터를 이용해 예측한다.
6.  **k가 작을수록:** 모형이 복잡해진다.
7.  **Training Error:** 학습에 사용한 데이터의 오차.
8.  **Test Error:** 새로운 데이터의 예측오차.
9.  **Overfitting:** 학습자료에는 지나치게 잘 맞지만 새로운 자료에 대한
    예측력이 떨어지는 현상.
10. **복잡한 모형이 항상 좋은 것은 아니다.**
11. **복잡도 증가:** 일반적으로 Bias ↓, Variance ↑.
12. **Curse of Dimensionality:** 차원이 증가할수록 국소적인 이웃을 찾기
    어려워지는 현상.

------------------------------------------------------------------------

> 데이터에서 적절한 규칙을 학습하여 처음 보는 데이터까지 잘 예측하는
> 것이다.**
