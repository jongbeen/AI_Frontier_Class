## 4-1. 의사결정나무란? `P.2~P.5`

### 예제로 감 잡기 `P.3`
신용상태(Credit status)를 예측하는 나무 예시:

```
[전체 323명: Bad 168, Good 155]
        │
   ┌────┴────┐
Income<2130$          Income≥2130$
[Bad 143, Good 22]     [Bad 25, Good 133]
   │                        │
Job으로 또 분리          Age로 또 분리
```

- 맨 위에서 시작해서, "Income이 2130달러보다 작은가?" 같은 **질문(조건)** 으로 데이터를 계속 둘로 쪼개나감
- 쪼갤수록 각 그룹 안의 신용상태(Bad/Good)가 점점 한쪽으로 쏠리는 걸 볼 수 있어 (예: Job A,B 그룹은 Good이 100%)
- 즉, "몇 가지 질문만 던지면 이 사람의 신용상태를 꽤 정확히 맞출 수 있다"는 걸 나무 모양으로 표현한 것

### 구성요소 (용어 정리) `P.4~P.5`

| 용어 | 뜻 |
|---|---|
| **뿌리마디 (root node)** | 나무가 시작하는 맨 꼭대기 마디 — 전체 데이터 |
| **자식마디 (child node)** | 한 마디에서 갈라져 나온 아래쪽 마디들 |
| **부모마디 (parent node)** | 자식마디 입장에서 바로 위 마디 |
| **끝마디 (terminal node)** = 리프(leaf) | 더 이상 갈라지지 않는 마디 (자식이 없음) — 최종 예측값이 여기서 나옴 |
| **중간마디 (internal node)** | 부모도 있고 자식도 있는, 나무 중간에 낀 마디 |
| **가지 (branch)** | 뿌리마디부터 끝마디까지 이어지는 하나의 경로 |
| **깊이 (depth)** | 뿌리마디부터 끝마디까지 거쳐가는 중간마디의 개수 |

> 💡 P.5의 그림에서 (1)번이 뿌리마디, (2)(3)이 중간마디, (4)(5)(8)(9) 등이 끝마디로 표시되어 있으니 그림과 용어를 같이 대조해보면 확실히 이해돼.

## 4-2. 의사결정나무 구축방법 `P.6~P.30`

### 전체 4단계 `P.7`
1. **나무의 성장 (growing)**: 각 마디에서 최적의 "분리규칙"을 찾아 나무를 키움. 정지규칙을 만족하면 멈춤
2. **가지치기 (pruning)**: 예측을 망치는 위험한 가지, 불필요한 가지를 잘라냄
3. **타당성 평가**: 평가용 데이터나 교차확인법으로 나무를 검증
4. **해석 및 예측**: 완성된 나무를 해석하고 실제 예측에 사용

### 1) 분리규칙 `P.8`
각 마디에서 나무를 가를 때 두 가지를 정해야 해:
- **분리변수(split variable)**: 어떤 입력변수로 나눌지 (예: Income? Age?)
- **분리기준(split criterion)**: 어떤 값을 기준으로 나눌지

| 변수 종류 | 분리 방식 |
|---|---|
| **연속형** (숫자) | 기준값 `c` 하나 정해서, `X < c`면 왼쪽, `X ≥ c`면 오른쪽으로 |
| **범주형** (카테고리) | 전체 카테고리를 두 그룹으로 나눔. 예: {1,2,3,4} → {1,2,4} vs {3} |

### 2) 순수도(purity) / 불순도(impurity) `P.9~P.12`
- **핵심 원칙**: 분리변수와 분리기준은 "**분리 후 자식마디가 목표변수를 얼마나 잘 구별해주는지**"로 정함
- **순수도**: 한 마디 안에 한 그룹(예: Good 또는 Bad)이 얼마나 몰려있는지의 정도
  - 예: (45%, 55%)로 섞인 마디보다 (90%, 10%)로 쏠린 마디가 **순수도가 높음** (불순도는 낮음)
- 분리를 할 때는 "**자식마디들의 순수도 합이 최대가 되도록**" 즉 불순도가 최소가 되도록 분리변수·기준을 고름

**⚠️ 왜 단순 오분류율만으로는 부족한가 `P.11~P.12`**

두 분리 방식을 비교해보자 (총 800개, 각 400/400):

| | 그룹1 | 그룹2 | 오분류율 |
|---|---|---|---|
| **Split 1** | (300,100) | (100,300) | 200/800 |
| **Split 2** | (300,100) | (200,0) | 200/800 |

- 둘 다 오분류율은 200/800으로 **똑같음**
- 하지만 Split 2는 오른쪽 마디가 **완벽하게 한 그룹(200,0)** 이 되었으니 훨씬 더 "순수한" 분리야
- → 단순 오분류율만 보면 이 차이를 못 잡아냄. 그래서 더 정교한 불순도 측정량이 필요함

### 3) 불순도 측정량 3가지 `P.13~P.19`
회귀(연속형 목표변수)는 F통계량·분산감소량을 쓰고, **분류(범주형 목표변수)** 는 아래 3가지가 대표적이야. 모두 같은 예시 표로 계산해봐:

| | good | bad | total |
|---|---|---|---|
| left | 32 | 48 | 80 |
| right | 178 | 42 | 220 |

**(1) 카이제곱 통계량 `P.14~P.16`**
```
카이제곱 = Σ (기대도수 - 실제도수)² / 기대도수
```
- "만약 good/bad 비율이 left/right에서 완전히 같았다면 나왔을 값(기대도수)"과 "실제 관측값"의 차이를 봄
- 값이 **클수록** left와 right가 서로 다르다 = 분리가 잘 됐다는 뜻 → **가장 큰 값을 주는 분리를 선택**
- 이 예시에서는 카이제곱 = 46.75

**(2) 지니지수 (Gini Index) `P.17`**
```
지니지수 = P(left에서 good) × P(left에서 bad) + P(right에서 good) × P(right에서 bad)
```
- 각 마디 안에서 두 클래스가 얼마나 섞여있는지를 곱으로 계산 (한쪽으로 완전히 쏠리면 곱이 0에 가까워짐)
- 값이 **작을수록** 순수함 → **가장 작은 값을 주는 분리를 선택**
- 예시: 지니지수 = 0.3944

**(3) 엔트로피 지수 (Entropy Index) `P.18~P.19`**
```
엔트로피 = Σ [P(그룹) × log(P(그룹))]  (모든 left/right × good/bad 조합에 대해)
```
- 정보이론에서 온 개념 — "불확실성"을 측정
- 마찬가지로 **작을수록(음수로 클수록 순수)** 좋은 분리 → 최소화하는 분리 선택
- 예시: 엔트로피 = -0.4796

> 💡 세 방법 모두 "이 분리가 good/bad를 얼마나 잘 갈랐는지"를 재는 서로 다른 수학적 잣대일 뿐, 목적은 동일해.

### 4) 실전 예제 — 지니지수로 최적 분리 찾기 `P.20~P.26`
날씨 데이터(Temperature, Humidity, Windy → Class: N/P)로 첫 분리를 정하는 과정:

| 분리변수 | 분리기준 | Gini index |
|---|---|---|
| Temperature | {hot} vs {mild,cold} | 0.3975 |
| Temperature | {mild} vs {hot,cold} | **0.373** ← 가장 작음 |
| Temperature | {cold} vs {hot,mild} | 0.49 |
| Humidity | {high} vs {normal} | 0.489 |
| Windy | {false} vs {true} | 0.472 |

→ 모든 후보 중 **Gini index가 가장 작은** "Temperature: {mild} vs {hot,cold}" 분리를 선택 (`P.26`)
→ 즉 실제로는 "가능한 모든 변수 × 모든 분리기준"을 다 계산해보고 불순도가 최소인 걸 고르는 **완전 탐색(brute-force)** 방식이야.

### 5) 정지규칙 (Stopping Rule) `P.27`
나무가 더 이상 커지지 않도록 멈추는 조건들:
- 한 마디의 모든 데이터가 이미 한 그룹에 속할 때
- 마디 안의 데이터 수가 너무 적을 때 (더 쪼갤 표본이 부족)
- 불순도 감소량이 미미할 때 (더 쪼개봐야 의미 없음)
- 뿌리마디로부터의 깊이가 정해진 한도를 넘을 때

### 6) 가지치기 (Pruning) `P.28~P.30`
**왜 필요한가**: 나무를 끝까지 키우면(마디가 아주 많아지면) 훈련데이터에는 완벽하게 맞지만, 새 데이터에는 예측이 부정확해질 수 있음 (과적합) → §3강에서 배운 "과대적합" 문제와 똑같은 논리야.

**비용복잡도(Cost Complexity)로 가지치기 `P.30`**
```
비용복잡도(a) = 나무 T의 오분류율 + a × |T|
```
- `|T|` = 끝마디의 개수 (나무 크기)
- `a`(알파): 나무 크기에 대한 벌점 강도 — **3강의 λ(조율모수)와 완전히 같은 역할**을 함
- 나무가 커지면 오분류율은 줄지만, `a|T|`(벌점)가 커지니 비용복잡도가 항상 줄진 않음
- `a`가 클수록 최적 나무 `T(a)`가 작아짐(=더 많이 잘림)
- 최적의 `a`는 평가용 데이터나 교차확인법으로 찾음

> 💡 3강에서 배운 "벌점화(라쏘/능형)"와 여기 "가지치기"는 사실 같은 아이디어의 다른 버전이야: 모델이 너무 복잡해지지 않도록 벌점을 줘서 억제하는 것.

## 4-4. 의사결정나무의 장점 / 단점 `P.31~P.35`

### 장점 `P.32~P.33`
- 이해하기 쉬운 규칙을 만들어줌 (사람이 눈으로 봐도 "왜 이렇게 예측했는지" 알 수 있음)
- 분류 작업(새 데이터 예측)이 간단함
- 연속형 변수와 범주형 변수를 모두 처리 가능
- 어떤 변수가 가장 중요한지 명확히 드러남
- **이상치(outlier)에 덜 민감함**
- 선형성·등분산성 같은 모형 가정이 필요 없는 **비모수적(non-parametric) 모형**

### 단점 `P.34~P.35`
- 목표변수가 연속형(회귀)일 때는 예측력이 떨어지는 편
- 나무가 너무 깊어지면 예측력도 떨어지고 해석도 어려워짐
- 계산량이 많을 수 있음
- **비사각영역(대각선 경계)** 을 잘 표현 못함 — 나무는 항상 축에 수직인 직선(가로/세로)으로만 자르기 때문
- **결과가 불안정함** — 데이터가 조금만 바뀌어도 나무 구조가 크게 달라질 수 있음
- 선형성이나 주효과를 잘 표현하지 못함

### 불안정성 예시 `P.36`
같은 Boston Housing 데이터에서 **부트스트랩(bootstrap)** 으로 살짝 다르게 뽑은 두 표본으로 나무를 만들었더니, 완전히 다른 모양의 나무가 나온 그림이 있어. 이게 "결과가 불안정하다"는 단점을 시각적으로 보여주는 예시야.
> 💡 이 불안정성 문제를 해결하려고 나온 게 나중에 배울 **랜덤포레스트(Random Forest)** 같은 앙상블 기법이야 (여러 나무를 평균내서 안정성을 높임).

## 한눈에 보는 핵심 정리표

| 개념 | 핵심 |
|---|---|
| 나무의 구성 | 뿌리마디 → (분리) → 중간마디 → (분리) → 끝마디 |
| 분리 기준 선택 | 불순도(카이제곱/지니/엔트로피)를 최적화하는 변수·기준 선택 |
| 나무가 너무 커지는 것 방지 | 정지규칙(성장 중 멈춤) + 가지치기(다 키운 후 잘라냄) |
| 가지치기 원리 | 비용복잡도 = 오분류율 + a×(끝마디 수) → a로 크기 조절 (3강의 λ와 같은 역할) |
| 장점 | 해석 쉬움, 이상치에 강함, 비모수적 |
| 단점 | 불안정함, 연속형 예측 약함, 대각선 경계 표현 못함 |
